# AI Projects

Hands-on AI engineering projects, built by a data engineer with 6 years of experience who is learning to design, build and ship AI-powered systems.

Each project focuses on something practical: taking raw data, turning it into something an AI model can use, and putting it behind a working application, with the same attention to pipelines, data quality and reproducibility that production data engineering demands.
